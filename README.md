# 残灯の深淵

**[ゲームを遊ぶ](https://cac-gwd.github.io/zanto-depths/)** · **v1.0.0** · [更新専用ページ](https://cac-gwd.github.io/zanto-depths/update.html)

敵を知り、退路を選び、最後の灯を守る。20階の戦術ローグライクです。iPhoneの縦画面・タッチ操作を中心に、PCでも遊べます。

前作「灯の迷宮」とは別ゲームです。公開URL、保存キー、Service Workerのスコープとキャッシュを分離しています。前作のセーブをこのゲームに読み込むことはできません。

## 深淵を生き延びる

- 敵・床をタップすると説明。閲覧と照準キャンセルでは時間が進みません。
- 8方向パッドで移動、敵へ進むと近接攻撃。壁の角は斜めに抜けられません。
- 射撃・投擲は対象を選んでから「実行」。道具使用、装備、防御、置く、交換も1手です。
- 地図の斜線と敵上の数字は危険な攻撃の範囲と発動までの手数。強い敵には隙があります。
- 支援役を倒す、射線を切る、部屋から退く、道具で分断するなど、敵ごとに異なる対処が必要です。
- 全滅させる必要はありません。階段を降りれば次の階へ。10・15・20階は主の撃破が必要です。
- 死亡時は死因と直前の出来事を表示。同じseedで再挑戦できます。恒久的な能力強化はありません。

## 20階の構成

| 階 | 区域 | 特徴 |
| --- | --- | --- |
| 1～5 | 崩れた関所 | 群れ、盾、射撃、突進。5階には守り手のいる任意の強力な道具 |
| 6～10 | 菌床の祭壇 | 毒・睡眠・封印・回復・召喚。10階は双鐘の番人 |
| 11～15 | 反響の牢域 | 引き寄せ、吹き飛ばし、支援範囲、反射。15階は鎖庭の主 |
| 16～19 | 消灯の聖域 | 逃げ火、処刑鎧と特殊敵の混成 |
| 20 | 深淵の灯炉 | 残灯王。体力に応じて3段階の攻撃パターン |

通常敵20種とボス3種を実装しています。全敵の能力・対処は「? → 敵図鑑と対処」で読めます。

## 道具・装備・技能

道具20種。回復、食料、矢、投げ槍、回数制の杖、状態異常、煙、氷壁、炎、転移、索敵など。16枠の道具袋から「置く・交換」ができます。足元の道具は「待つ」か再び踏むと拾います。

武器は刀・槍・毒短剣・弓。防具、3種類の護符と組み合わせます。装備変更は1手で、外した装備は袋へ戻ります。

2・5・8・11・14・17階の到達で技能ポイントと少量の生命成長。強襲・守勢・呪毒・狙撃・道具術の5系統から自由に選びます。各3段階、1回の冒険で6ポイントです。召喚獣を倒して経験値を稼ぐ仕組みはありません。

## 状態と資源

- 4手ごとに満腹度が1減少。0になると毎手生命1減少。
- 空腹や毒でなければ10手ごとに生命1回復。
- 防御はその手の通常ダメージを3軽減。守勢で強化できます。毒・飢え・炎床は防具と防御では防げません。
- 睡眠は1手の行動を失います。被弾でも解除。解除後は短時間の再睡眠耐性があります。
- 封印は道具と装備の使用を止めます。移動・射撃・置くは可能です。
- 新しく視認した敵は即攻撃せず、反応する一手があります。危険な能力には予告を設けています。
- 毎階に回復薬2個、保存食・非常食・矢束・解毒薬を配置します。拾えるか、寄り道すべきかは地形と敵次第です。

## iPhoneで遊ぶ

Safariでゲームを開き、共有 →「ホーム画面に追加」。追加したアイコンからオンラインで一度起動し、「オフライン準備完了」を確認してください。その後は通信なしでも遊べます。

セーブは一手ごとに端末内へ保存します。「?」からファイルの書き出し・読み込みができます。ブラウザのデータを消すとセーブも消えるため、必要な冒険は書き出してください。Safariとホーム画面アプリで保存領域が分かれる場合があります。複数タブでの同時プレイは対応しません。

表示中のバージョンはタイトル横と「?」にあります。更新ページはセーブを削除せず、新版を取得して切り替えます。初回アクセスと更新には通信が必要です。

## 開発・検証

外部依存なしのHTML/CSS/JavaScript。ビルド不要です。Node.jsを用意して実行します。

```sh
npm start
# http://127.0.0.1:4180
npm test
```

テストでは20階×10シードの到達性と配置、全敵のターン実行、予告の回避、盾・支援・状態異常・爆発・引き寄せ・杖の回数、ボスの階段封鎖、保存往復、オフライン資産、前作キャッシュの保護を確認します。

初期リリースのバランスです。初見のクリア率や熟練者に対する難易度は、実際のプレイで継続調整する必要があります。iPhone実機でのインストール・機内モードは未検証です。効果音・音楽はありません。

更新時は `data.js`、`index.html`、`package.json`、`sw.js`、READMEのバージョンをそろえます。セーブ形式のバージョンと公開バージョンは別です。

## 生成方式

部屋・迷路・洞窟の生成コードは、前作の独自実装を別ファイルとしてコピーし、新作で独立管理しています。旧ゲーム側のファイルを実行時に参照しません。

参考資料：[BSPによる部屋生成](https://chizaruu.github.io/roguebasin/basic_bsp_dungeon_generation)、[セルオートマトンによる洞窟生成](https://www.roguebasin.com/index.php/Cellular_Automata_Method_for_Generating_Random_Cave-Like_Levels)。既存作品のキャラクター・画像・音楽は使用していません。
